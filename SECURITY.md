# 🔒 Security Policy

## 📌 Supported Versions

The following versions of this project are currently being supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| Latest  | ✅ Yes             |
| Older   | ❌ No              |

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

### 📫 How to Report
- 📧 Email: aswanvijoy@gmail.com  
- 🐦 Twitter (X): https://x.com/AswanVijoy  

---

### 🛡️ What to Include
Please include the following details in your report:

- Description of the vulnerability  
- Steps to reproduce the issue  
- Possible impact  
- Screenshots or proof-of-concept (if available)  

---

## ⏱️ Response Time

- 📥 Acknowledgement within **48 hours**  
- 🔍 Initial assessment within **3-5 days**  
- 🛠️ Fix and update timeline will depend on severity  

---

## 🔐 Responsible Disclosure

- Please **do not publicly disclose** the issue until it has been resolved  
- Avoid exploiting the vulnerability beyond what is necessary for proof  
- Respect user data and privacy  

---

## ⚠️ Scope

This policy applies to:
- Source code in this repository  
- Project dependencies  
- Deployment configurations (if applicable)  

---

Thank you for helping keep this project secure!  
Your efforts are greatly appreciated 🚀
